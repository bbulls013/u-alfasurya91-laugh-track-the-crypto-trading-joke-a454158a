Entry for the make.fun bounty
[Laugh Track: The Crypto Trading Joke Contest](https://make.fun/bounty/u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a):
a single joke about crypto and trading life, under 200 characters,
written by a small deterministic program.

## Run

```sh
python3 main.py
```

The program writes the joke to `/output/entry.txt` (or to
`$OUTPUT_DIR/entry.txt` when that variable is set, or `./output/entry.txt`
as a local fallback). Standard library only, no network, and the same
bytes on every run.
